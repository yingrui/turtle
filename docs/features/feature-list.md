# 功能清单

按"用户要做的四件事"组织，页面归属与 `information-architecture.md` 的目标树一致。每个功能写清：
做什么、输入、输出、现状。现状标记：✅ 已有　🟡 部分可用　⬜ 还没有

| 清单区块 | 目标树里的位置 |
|---|---|
| A 概览 | 概览（单一入口，不成分组） |
| B 选股 | 投资 → 选股 |
| C 我的组合 | 投资 → 我的组合 |
| D 选股方法 | 研究 → 选股方法（D8 因子库不在菜单里，从方法进入） |
| E 回测 | 研究 → 回测（基线是新建回测的选项，没有独立页面） |
| F 行情 / 指数 | 数据 → 行情 · 指数（F5 无独立页面，在个股详情里） |
| G 系统 | 系统 → 任务 · 设置（G3 费率在设置内）· 数据 → 数据状态（G1） |
| H 支撑 | 不在菜单里：数据接入、因子计算、数据集、同步 |

## 缺口排序（按对"四件事"的影响）

1. **E6/E7 基线 + σ**：没有它，回测只能看收益，判断不了真假 —— 研究动线缺最后一环。
2. **E1 回测不再要求组合**：这是"组合被污染"的根源，也是策略参数无法复用的原因。
3. **G3 费率设置**：硬编码费率意味着所有历史回测都在用同一套假设，且无法调整。
4. **A2 今日方法结果**：日常动线目前要跳到方法页逐个看。
5. **D7 打分与后续收益的关系**：没有这个，方法好不好只能靠回测，成本高十倍。
6. **B4/B5 保存池与从条件建方法**：选股与研究现在是断开的，人工搬运。
7. **C6 组合 vs 指数**：真实账户没有基准，看不出"我这个月算好还是差"。
